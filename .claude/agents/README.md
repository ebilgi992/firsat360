# Proje ajanları (The Agency)

Kaynak: https://github.com/msitarzewski/agency-agents (MIT lisansı, © Michael Sitarzewski ve katkıda bulunanlar), commit `4e3ac3c`.
FIRSAT360 için seçilmiş 18 uzman ajan; bu depoyu açan her Claude Code oturumunda kullanılabilir.
Tüm roster (≈280 ajan) için: `git clone --depth 1 https://github.com/msitarzewski/agency-agents && ./scripts/install.sh --tool claude-code --no-interactive`.

Kullanım eşlemesi: mobil (mobile-app-builder, mobile-release-engineer), kod incelemesi (code-reviewer, minimal-change-engineer),
mimari (software-architect), test (reality-checker, evidence-collector, test-automation-engineer, api-tester, accessibility-auditor),
güvenlik/gizlilik (appsec-engineer, privacy-engineer), UX (ux-architect, ui-designer), ürün (product-manager, sprint-prioritizer),
CI (devops-automator), dokümantasyon (technical-writer).
